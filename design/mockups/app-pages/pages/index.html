Magpie · Sign-in, Item, Stores

Mockups for three pages of the app layout epic. Each frame below is live. The interactive prototype starts at sign-in and taps through to the list, an item, and the stores. Store, item and price values are sample data.

#3 Sign-in#7 Item#6 Stores and Store

Sign-in

For #3 Sign-in page. The only page without the main navigation. Sign in with Google; a finished sign-in opens the List page. An account outside the household is turned away with a way to try another account.

Item

For #7 Item page. Name, quantity, note, photo, and the zone it sits in at each store. Prices show the last price at each chain and the change since the trip before. Add to list (new item) or Done (existing item) returns to the List page.

Stores and Store

For #6 Stores and Store pages. Opened from the More menu. Stores are grouped by chain, because prices compare per chain. A Store page shows the map and its zones, with Edit map (or Draw the map) opening the Map editor.
