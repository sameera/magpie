# Delivery Lessons

Process and delivery lessons, written by `/nxs.close` at the end of each epic.

## Convention

- One file per lesson: `<date>-<slug>.md` (e.g. `2026-10-03-offline-testing-gap.md`).
- Frontmatter records the source epic:

    ```yaml
    ---
    source-epic: <epic issue number>
    date: <YYYY-MM-DD>
    ---
    ```

- Body: what happened, why, and what to do differently. Keep it short.
- Lessons are about process and delivery. Technical decisions belong in decision records and `docs/system/standards/`.
